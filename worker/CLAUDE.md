# Cloudflare Worker (Relay Server)

JavaScript-based WebSocket relay using Cloudflare Workers + Durable Objects. The relay forwards encrypted messages between devices without being able to decrypt them.

## Deployment

- **Platform**: Cloudflare Workers
- **Deploy**: `wrangler deploy` from this directory
- **Config**: `wrangler.toml`
- **Durable Object**: `Room` class with SQLite migration (tag: v1)
- **R2 Bucket**: `casttv-assets` (binding: `ASSETS`) for APK distribution

## Endpoints

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/room/:code/ws?role=<role>` | GET (WS upgrade) | WebSocket relay entry point |
| `/room/:code/status` | GET | Connection status query (rate-limited) |
| `/download/android` | GET | Serves `android/casttv.apk` from R2 |

**Roles**: `appletv`, `androidtv`, `iphone`

## Room Durable Object

Each room code maps to one Durable Object instance (`env.ROOM.idFromName(code)`).

### Connection Rules
- **Max 1 TV per room**: Second `appletv`/`androidtv` connection returns 409
- **Unlimited phones**: Multiple `iphone` clients can coexist
- Room codes must be exactly 6 alphanumeric characters (uppercase normalized)

### Message Routing
1. Client sends message (encrypted, opaque to relay)
2. Relay forwards to **all other connections** in the room (excluding sender)
3. Relay failures logged but don't disconnect the sender

### System Messages (unencrypted, generated by relay)
```json
{ "type": "device_joined", "role": "iphone", "timestamp": "..." }
{ "type": "device_left", "role": "appletv", "timestamp": "..." }
```
Sent to all existing connections when a device connects/disconnects.

## Rate Limiting

- **Status endpoint only**: 30 requests per 60-second window per IP
- **IP source**: `CF-Connecting-IP` header
- **Exceeded**: Returns 429 with `Retry-After: 60`
- **Pruning**: In-memory map, entries cleaned when map exceeds 10,000

## CORS

Enabled on all responses: `Access-Control-Allow-Origin: *`

## Key Files

```
src/index.js       # Main worker + Room Durable Object class (~250 lines)
wrangler.toml      # Cloudflare configuration (DO bindings, R2 bucket, compat date)
test-ws.mjs        # WebSocket integration test
package.json       # Dependencies (none — pure Cloudflare APIs)
```

## Important: The Relay is Blind

The worker never sees plaintext. All application messages are encrypted with AES-256-GCM on the client side before being sent. The relay only sees base64-encoded ciphertext and forwards it as-is. Only `device_joined`/`device_left` system messages are unencrypted.
